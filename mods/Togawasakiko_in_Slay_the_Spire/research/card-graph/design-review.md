# 全卡池设计评价与攻击候选

2026-09-21；源码基线 0.2.3 / `057b6396`。本页是设计判断，不是已批准规格。
详细节点、基础/升级效果及条件边见 [交互图](index.html) 与 [JSON](graph.json)。

## 结论

值得增加攻击，但目的不是把技能与攻击的数量凑平。更有价值的是让现有的整理手牌、防御积累能转为有上限的攻击选择，
同时保留压力路线内部的取舍。**优先讨论改写重拍，其次比较收束终止式；断奏保留，不默认三张一起加。**

主池 63 张：16 攻击、39 技能、8 能力；常规奖励池 58 张：13 攻击、37 技能、8 能力。
17 张 Common 中只有 4 张攻击：Symbol I、祥，移动、斩断过去、'S/' The Way。
这些数字说明低稀有度攻击选择较少，但不直接证明伤害不足，更不能把 26 张 Song 都视为技能。
完整 72 节点另含压力衍生、事件与遗物授予牌，它们不能混入奖励出现率统计。

## 已有系统并非几条孤立流派

| 系统 | 旧牌骨架与实际连接 | 设计判断 |
| --- | --- | --- |
| 存压 | 难熬、完美无缺、Ether、日记本、Masquerade提供压力；中伤、十字架X、黑色生日、KillKiss读取存量或门槛 | 终端已经很多，再加一张“压力够就多伤害”不一定补缺口 |
| 兑换 | 面具戴好、利刃穿心、保释金、Angles/Symbol II/Sophie等成功Debuff兑换衍生牌；兑换会减少压力 | 应呈现“先兑换还是先读存量”的牌序，不把兑换与存压无条件画成双赢 |
| 控制反馈 | 天真给自闭，自闭实际伤害进入日记本；自卑让伤害事件减力量，压力足够时继续兑换 | 新攻击尤其多段必须计算控制与衍生收益，不能只按每费伤害定价 |
| 力量与多段 | 她在发光清压换力量；举重冠军付生命成长；绝望的黎明、终幕、Symbol I、十字架X承接逐段收益 | 现有多段供给不稀缺；新牌避免以低成本再复制一个六段攻击 |
| 生命预算 | 神明笨蛋、举重冠军、'S/' The Way、蓝世界付生命；Masquerade读取当前缺血；脆弱/交给我吧/大狗回复 | 自伤已经能连起多条线，不宜再把人物主题等同于不断扣血；回复同时改变Georgette分支 |
| 颜与格挡 | Face、面具戴好、脆弱给颜；怪物正伤害事件延迟施压；Symbol III等格挡保护反应窗口 | 揭下面具已提供主动兑现，不必再造一个几乎相同的揭面；可以比较格挡的有限攻击出口 |
| 弃牌与编排 | 完美无缺、兴奋不已、好多蛆、Choir有明确弃牌；斩断过去、日记本、被囚禁12和抽牌入口推动周转 | 已有整理工具多，但欠缺一个不再生牌、不回能的有限攻击收益点 |
| 消耗与重演 | 复权、说话、脆弱、谱曲等旧消耗牌；Choir重放消耗堆，碧眼重放歌曲；余音回馈实际消耗 | 消耗不是“一次性”可靠限幅器，设计必须按重放重付资源审查 |
| Song执行 | 谱曲/蓝世界生成，排练检索，未完成乐谱置顶；两轮月亮累计本战歌数；Symbol组合、八芒星限制顺序 | 新非Song攻击能填类型选择，但不会自动进入Song池或为两轮月亮减费 |

这些是图的解释，不是推荐每局凑齐全部机制。力量、伤害、施压、抽牌和重放都有机会成本与时点。
特别是敌方行动产生的颜压力赶不上同一次敌方回合开始的 KillKiss 检查；
Ave Mujica 在常规抽牌之后才处理剩余牌顶，不能把前回合置顶直接等同于免费打出。

## 候选一：改写重拍

**暂定 Common / 非Song攻击 / 1费。** 造成6（9）伤害。本回合你每弃置1张牌，伤害增加2，最多计算3张。
无其他修正时基础范围6～12，升级9～15；不自带弃牌、抽牌、回能或消耗。

支持它的不是某一张新牌，而是完美无缺、兴奋不已、好多蛆、Choir这组早已存在的整理工具。
好多蛆即便净化队友，弃牌也由自身承担，不能读取队友独立弃牌。兴奋不已无歌的回能分支不增加计数。
她在发光清空压力后，这张攻击仍能读取已发生的弃牌，不会和中伤争抢同一存量。

为什么限制3张：避免完美无缺大换手与反复弃抽把普通攻击推成无界终结技。
为什么不附带抽牌：它只兑现已有整理成本，不自己同时建立、复制和支付循环。
正常打出后移入弃牌堆不是一次主动弃牌事件；将来必须按原版弃牌事件/历史核对，不能按牌堆目的地计数。

主要风险：两张完美无缺等大幅提高满额稳定性；Treasure Pleasure可重复读取满额计数，
两次完整结算为24（30）基础伤害，不是整条重放链被封在12（15）。还需检查同回合三次以上重放与自动打出的时机。
这是最值得先打样的一张，但尚无实战数值结论。

## 候选二：收束终止式

**暂定 Common / 非Song攻击 / 1费。** 失去8点格挡，不足则失去全部。造成6（9）伤害，并增加等于实际失去格挡的伤害。
单次基础上限14（17）；自动支付 `min(当前格挡,8)`，没有选数量弹窗，也不要求先有8格挡才能打出。

起始防御、难熬、脆弱、Face、Symbol III早已覆盖多种格挡来源；幕后支撑、不必说出口仅是额外入口。
相较只和最新压力牌搭配，这张从起手牌就能做选择：保留防御，还是花一部分换取斩杀窗口。
它与SheIsRadiant的力量、自卑/回响的命中反应、KillKiss的当前HP门槛都有关系，不能只计算格挡兑换率。

每次完整重放重新支付格挡。只有8格挡时，两次为20（26）；有16格挡才到28（34）。
8点上限阻止Symbol III在同一run跨战斗成长直接变成无上限伤害；不是跨run账户成长。
失去格挡不是受到攻击或失去HP，不触发颜；八芒星只免能量，不免这份格挡代价。

主要风险：玩家会把它当“没来攻击时又一张6伤”，或者在有敌方攻击时付防御变成纯损失。
若早期拾取表现差，优先重新评估费用/基础伤害/上限三者之一，不先塞入回能或保留来掩盖问题。
不和改写重拍同时默认加入，先比较哪一张真正改善普通奖励选择。

## 保留案：断奏

**暂定 Common / 非Song攻击 / 1费。** 可消耗手中1张压力衍生牌；造成6（9）伤害，成功支付则再造成6（9）。
消耗的是材料，攻击本身不带Exhaust；一次出牌两段伤害，不是两次打出。

旧复权、诅咒、说话和Ave Mujica均可提供材料，不只依靠DIVINE等新牌。
但同一张免费人格解离若直接打出可能给下一次伤害翻倍，消耗它只换第二段未必划算；
材料还与DIVINE的回能过牌、不必说出口的格挡竞争。主动消耗可触发余音，不能触发幕后支撑的“打出”。
力量、自卑和绝望回响会逐段放大收益；Treasure Pleasure每次重放必须再付一张材料，两次全付是24（36）。

降低优先级的原因：已有衍生牌支付出口，不缺把衍生牌当货币的技能。
这张只有在测试显示该分支确实缺低成本攻击兑现时才有必要，不能仅因画了很多边就认定它更好。

## 人物与题材约束

沿用[两部连续人物研究](../design-expansion-2026-07/03-source-character-research.md)作为设计解释，不把本页新卡名当原作台词或歌曲。
“改写”对应重新组织已放下的材料，“收束”对应主动选择结束与付出代价，
都试图保留MyGO时期的编排、旧关系与Ave Mujica时期的舞台控制之间的连续性，而非仅画新乐队合照。
这些对应关系是二创设计判断，不是官方对某个游戏机制的解释；本轮没有重做原作事实研究。
三张均非真实曲目，暂不标Song，也不以专辑封面直接代替尚未确定的卡意。

## 实现前必须完成

1. 用户决定是否采用，以及优先测试哪张；当前只批准图谱形式。
2. 反编译对应版本的原版弃牌统计、格挡移除、攻击伤害、可选材料选择与自动出牌流程；先找原版接口再实现，不写自己的回合清理时钟。
3. 测基础/升级预览、力量/虚弱/易伤、0与上限资源、同回合重复出牌、战后重置、同名多实例、保存加载、两个祥子和队友历史隔离。
4. 纳入旧牌组合：完美无缺/兴奋不已/好多蛆；难熬/Face/Symbol III/Sophie；Treasure Pleasure/自卑/回响/八芒星；压力清空与KillKiss门槛。
5. 观察早期普通奖励、精英战和低资源手牌表现。图上的连接数量不能替代拾取率、平均收益、启动成本与极端循环测试。
