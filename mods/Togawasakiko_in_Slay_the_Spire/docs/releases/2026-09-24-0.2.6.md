# 2026-09-24 0.2.6

本版集中修复卡牌悬空、资源生命周期、自动打出与音频问题。继承 0.2.5 的角色战斗立绘、Spine 动作、施法接入与「从容应对」8/12 格挡，不回退或替换上一版美术资源。

## 修复内容

- 修复同一游戏进程中退出再继续后，攻击特效引用已释放场景，导致中伤、打击等卡牌停在空中。日志未显示「接续小节」是直接根因。
- 修复弹琴事件音频跨退出/继续失效、异常离场残留，以及远端玩家选项串扰本机画面和音乐。
- 磁力重放改走原版重复出牌流程，处理重复附魔递归、X 费用快照、次数叠加和强制消耗去向；目标处理与原版重复出牌保持一致。
- 群体敌人筛选排除友方奥斯提与不可命中单位。
- Ave Mujica 免费自动打出不再因能量或星星不足失效，真正的不可打出限制仍然有效。
- Jukebox 播放期间调整 BGM 音量不再引起原版音乐叠声；关闭或离开 run 后恢复最新音量设置。
- Shadow 卡存档重建保留获得楼层。

九类问题的原始证据、修复机制和验收清单见[稳定性审计](../../../../docs/audits/card-stall-and-risk-audit-2026-09-22.md)。

- Mac arm64 / Windows x86_64 的 STS2 v0.107.1 / 59260271 引用构建均 0 警告、0 错误。
- PCK 与已公开 0.2.5 对照 571 项内容资源，只有内嵌 manifest 的版本号变化；其余 570 项哈希一致。打包脚本 UID 不计为内容资源。
- 最终 PCK 原生加载、六种角色动作、光环与荆棘生命周期通过；荆棘渲染 1,181 个采样乘 3 个尺寸通过，无错误日志。
- ZIP 严格只含 DLL、PCK、外部 manifest 三件套，包内文件与 staging 逐字节一致；内外版本均为 0.2.6，最低游戏版本仍为 0.107.1。
